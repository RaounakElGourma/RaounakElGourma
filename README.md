# ✨ Featured Projects

## 👁️ TrackWear — Multi-Camera Person Tracking & Re-Identification

Multi-camera Computer Vision system for detecting, tracking and
re-identifying people across cameras using visual and clothing attributes
without facial recognition.

**Highlights**
- Person detection and multi-object tracking
- Clothing and visual attribute classification
- Clothing color extraction
- Cross-camera person re-identification
- Real-time CCTV / RTSP video processing
- Streamlit interface and SQLite storage

`YOLOv8` `ByteTrack` `EfficientNet` `OSNet` `PyTorch` `OpenCV` `Streamlit`

[View Portfolio →](https://raounakelgourma.github.io/Portfolio/#projects)

---

## 🤖 Smart Mouwatin — RAG-Based AI Assistant

AI assistant designed to help users access Moroccan administrative
information through document retrieval and LLM-based response generation.

**Highlights**
- Document chunking and preprocessing
- Embeddings and semantic search
- Vector database retrieval
- Retrieval-Augmented Generation
- LLM-powered response generation

`RAG` `LangChain` `ChromaDB` `Sentence Transformers` `Gemini API` `FastAPI`

[View Portfolio →](https://raounakelgourma.github.io/Portfolio/#projects)
